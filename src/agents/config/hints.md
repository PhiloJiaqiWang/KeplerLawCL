# Hint Database

## Kepler First Law

### Conceptual Problem
- Compare whether distances to one center stay constant across orbit points.
- Compare whether the sum of distances to both foci stays more consistent.
- Use multiple orbit points before deciding circle versus ellipse.

### Collaborative Problem
- Ask each partner to contribute one measurement and one interpretation.
- Put both partners' measurements side by side before choosing a model.
- Agree on which points to compare before drawing a conclusion.

### Emotional Problem
- Slow down and identify one measurement that feels reliable.
- Name what is confusing, then test only one claim at a time.
- Use the evidence table to restart from shared observations.

## Kepler Second Law

### Conceptual Problem
- Compare equal time intervals at different orbit locations.
- Check whether swept areas stay similar even when speed changes.
- Separate speed evidence from swept-area evidence before interpreting.

### Collaborative Problem
- Have both partners use the same time interval for comparison.
- Coordinate which side points each partner will measure next.
- Combine speed and swept-area measurements before making a claim.

### Emotional Problem
- Choose one fixed time interval and collect one clean comparison.
- Focus on what the latest measurements show, not the whole pattern yet.
- If the pattern feels unclear, compare only near-star and far-star points.

## Kepler Third Law

### Conceptual Problem
- Compare orbital period and semi-major axis across multiple orbits.
- Look for whether larger orbits also have longer periods.
- Use pairs of period and axis measurements from the same orbit.

### Collaborative Problem
- Split the orbit measurements so each partner contributes matching evidence.
- Build a shared table with period and axis for each orbit.
- Decide together which relationship the plotted evidence supports.

### Emotional Problem
- Start with two orbits and compare their period-axis pairs.
- Use the plot as a check instead of trying to infer everything mentally.
- If overwhelmed, collect one period and one axis measurement next.
